# Реестр источников права РФ для юридической базы «Догодок»

> Цель: собрать внутри сервиса юридическую базу, на которую ИИ может опираться при оценке
> любого договора в любой сфере (ссылки на нормы, акты, стандарты, судебную практику).
> Этот документ — **реестр ссылок и оценка покрытия**, а не скачивание. Ничего пока не тянем.
>
> Дата составления: 2026-08-21. Ссылки перепроверять перед интеграцией (порталы меняют схемы API).

---

## 0. Главный вывод (TL;DR)

1. **Первоисточник и юридически значимые тексты — только государственные порталы** (ФСО/Минюст).
   Официальные тексты правовых актов **не охраняются авторским правом** (ст. 1259 ГК РФ, п. 6 —
   официальные документы), поэтому их можно свободно загружать к себе и использовать в
   коммерческом сервисе. Это наш фундамент.
2. **Коммерческие СПС (КонсультантПлюс, Гарант) копировать/парсить нельзя.** Их
   консолидированные редакции, комментарии, аннотации и связи — объект их прав. Можно только
   легально ссылаться по официальной лицензии/партнёрскому API (платно).
3. **Реалистичный путь наполнения:** гибрид — bulk-загрузка официальных актов + периодическая
   синхронизация по API/открытым данным + для «горячих» кодексов держим собственные
   консолидированные редакции, собираемые из официальных изменений.
4. **Полностью «всё законодательство» одним архивом никто не отдаёт.** Базу собираем послойно:
   кодексы → профильные ФЗ → подзаконные акты → ГОСТ/техрегламенты → судебная практика →
   ведомственные разъяснения. Приоритет — по сферам договоров (раздел 4).

## 4. Коммерческие СПС (только по лицензии — не парсить)

| # | Источник | URL | Что даёт | Условие |
|---|----------|-----|----------|---------|
| 4.1 | **КонсультантПлюс** | https://www.consultant.ru | Консолидированные редакции, комментарии, связи, судебная практика. Есть **методы API** (просмотр/чтение). | Только по договору/лицензии. Копирование их редакций и парсинг — **нельзя**. Лицензия распространяется лишь на оговорённый вид использования. |
| 4.2 | **Гарант** | https://www.garant.ru | То же + **Гарант-Коннект API** (документы в HTML, экспорт изображений/формул). | Платно, по договору. |

**Юридический смысл:** сами тексты законов свободны (это официальные документы). Но
«добавленная стоимость» СПС — их редактура/консолидация/аннотации — защищена. Поэтому берём
**голые официальные акты из госисточников**, а консолидацию делаем сами (см. раздел 6), либо
покупаем доступ к СПС-API, если нужен готовый консолидированный слой.

| Судебное толкование (риски по любой сфере) | Пленумы ВС, обзоры ВС | vsrf.ru | ⚠️ вторичный слой, собрать выборочно |

**Главные пробелы для «полной оценки любого договора»:**
1. **Консолидированные (действующие) редакции кодексов и ФЗ.** Официальны с 01.07.2022 на
   pravo.gov.ru, но для более ранних версий и удобной структуры «статья → пункт» придётся либо
   собирать самим из актов об изменениях, либо покупать СПС-API.
2. **Подзаконные акты и ведомственная подзаконка** — их очень много; тянуть по мере
   приоритетных сфер, а не всё сразу.
3. **Судебная практика СОЮ** — после остановки единого агрегатора ГАС «Правосудие» цельного
   свободного источника нет; для MVP ограничиться Пленумами/обзорами ВС и КАД по арбитражу.
4. **ГОСТ/техрегламенты** — метаданные официальны, полные тексты отдельными файлами.

## 7. Рекомендуемая стратегия наполнения базы (черновик архитектуры)

**Слой 1 — эталонное ядро (обязательно, свободно):**
кодексы + топ-30 профильных ФЗ по сферам из раздела 6. Загрузка с pravo.gov.ru (ИПС/codex) +
OpenData. Хранить как структурированный текст: акт → статья → пункт (+ дата редакции, номер
изменяющего акта). Структура «статья/пункт» критична: ИИ должен ссылаться точечно.

**Слой 2 — инкрементальная синхронизация:**
демон, который по API офиц. опубликования (2.2) и OpenData (2.3) забирает новые акты/изменения
и версионирует наши редакции (принцип append-only, как версии договоров в проекте — не
перезаписывать, а добавлять редакцию).

**Слой 3 — практика и разъяснения (вторично):**
Пленумы ВС, обзоры ВС, ключевые письма ФНС/Минфина/Роспотребнадзора — как «толкование» для
оценки рисков. Точечно, по сферам.

**Слой 4 — стандарты (по требованию):**
метаданные ГОСТ из Росстандарта; полные тексты — под конкретные сферы (поставка/подряд/качество).

**Модель ссылок для ИИ:** каждый фрагмент базы = {акт, редакция, статья, пункт, URL
первоисточника}. Тогда ИИ в оценке договора даёт ссылку на конкретную норму, а не «где-то в ГК».

**Правовые предостережения:**
- официальные акты — свободно (ст. 1259 ГК);
- редакции/аннотации КонсультантПлюс/Гарант — **не копировать**;
- при использовании сторонних парсер-API судов проверять их право отдавать данные;
- фиксировать источник и дату загрузки каждого фрагмента (доказуемость актуальности).
