# Бесплатная загрузка готового документа как входная дверь

**Дата:** 2026-08-19
**Статус:** утверждено владельцем (брейнсторминг в чате)
**Связано:** `2026-08-19-token-prepaid-design.md` (предоплата токенами)

## Проблема

Загрузка готового Word-документа сейчас запутана и берёт лишние деньги:

- Две разные кнопки «Загрузить» ведут в разные места с разной ценой:
  - Главная → «Загрузить документ» → `/documents/upload` (сохранить как есть + **обязательный анализ 25 токенов**).
  - Список документов → «Загрузить» → `/documents/new?tab=upload` (**генерация ИИ за 100 токенов**, переписывает документ).
- Мастер `/documents/new` со вкладкой «Загрузить файл» переписывает документ ИИ (100 токенов) и требует настройку ИИ (юр.защищённость, объём, промпт) — это не «залить готовое».
- Пользователь, желающий просто сохранить документ, идёт через «Создать договор», не находит простой загрузки и получает списание 100.

Цель — сделать загрузку готового документа **бесплатной входной дверью**: сохранить как есть, хранить структурировано в бесплатном объёме памяти; платить пользователь начинает только когда правит документ.

## Решения владельца

1. Загрузка готового документа в систему — **бесплатно**, сохраняем как есть, храним в выдаваемом при регистрации объёме памяти (500 МБ уже есть в `storageQuota`).
2. Первая правка загруженного документа через чат — платно (**50 токенов**, открывает пакет 10 правок). Цена не меняется.
3. Анализ на риски — **опционально**, 25 токенов, не обязателен для сохранения. Цена не меняется.
4. Генерация с нуля / из шаблона / переписывание по образцу — платно (100 токенов), отдельный явный путь.
5. Точки входа должны быть **явными и различимыми**: пользователь заранее понимает, что платно сейчас, а что бесплатно (правки потом платные).
6. При загрузке — **попап-развилка**, честно объясняющая два пути.
7. Цены не менять: генерация 100, первая правка загруженного 50, анализ 25.

## 1. Явные точки входа

Единый набор действий везде (сайдбар, главная, список документов):

| Действие | Назначение | Цена |
|---|---|---|
| **Создать договор с Догодоком** (`/documents/new`) | генерация с нуля или из шаблона | 100 токенов |
| **Загрузить документ** (`/documents/upload`) | залить готовый Word как есть | бесплатно (правки потом платные) |

Изменения:
- Кнопка «Загрузить» в списке документов (`documents/page.tsx`) ведёт на `/documents/upload`, а НЕ на `/documents/new?tab=upload`.
- Вкладка «Загрузить файл» (`base='upload'`) убирается из мастера `/documents/new` — там остаются только «с нуля» (scratch) и «из шаблона» (template). Загрузка готового документа идёт только через `/upload`.
- Подписи кнопок несут цену/бесплатность: «Создать договор · 100 токенов», «Загрузить документ · бесплатно».

## 2. Экран загрузки `/documents/upload` — развилка

После выбора файла (и роли) пользователю предлагаются два явных действия вместо текущего единственного «Анализировать документ»:

- **«Сохранить в систему»** (бесплатно) — документ сохраняется как есть (`base='upload'`), попадает в список документов, занимает место в хранилище. Ничего не списывается. Правки — потом (первая через чат спишет 50 токенов).
- **«Проверить на риски»** (25 токенов) — запускает анализ (текущий флоу: оценка + риски + извлечение сторон с согласием ПДн), затем сохраняет. Кнопка показывает цену.

Обе кнопки сохраняют исходный текст без изменений ИИ. Перед сохранением — попап-предупреждение (см. ниже), если пользователь пришёл не с явным выбором.

### Попап-развилка (ключевое требование)

При инициации загрузки (клик «Загрузить документ») — окно, объясняющее модель:

> **Загрузка готового документа**
> • Сохранить как есть — бесплатно. Документ ляжет в ваш список и хранилище. Когда захотите его изменить через Догодок-чат — спишется 50 токенов (в них входит пакет из 10 правок).
> • Проверить на риски — 25 токенов. Догодок оценит документ и покажет риски.
>
> Чтобы создать новый договор с нуля через ИИ — используйте «Создать договор» (100 токенов).

Реализация попапа: либо модалка перед экраном `/upload`, либо две карточки-выбора прямо на экране загрузки после выбора файла. Выбираем второй вариант (две явные кнопки на экране `/upload` + короткая поясняющая плашка) — меньше кликов, развилка всегда на виду.

## 3. Механика

- **Бесплатное сохранение**: `POST /api/documents` с `uploadedContent` + `base='upload'` (уже существует, генерацию не запускает). Списаний нет — подтверждаем, что этот путь ничего не списывает.
- **Анализ**: `POST /api/documents/analyze` (25 токенов, уже есть) — вызывается только по кнопке «Проверить на риски».
- **Первая правка**: `UPLOAD_EDIT_START` = 50 токенов при первой правке через чат (уже реализовано в `chat/route.ts`).
- **Хранилище**: `storageQuota` (500 МБ при регистрации) уже есть; на экране загрузки и в списке документов подсвечиваем «храните готовые документы бесплатно», показываем занятое место (уже есть на главной/в хранилище).
- **Контрагент**: `Document.counterpartyId` в схеме обязателен, делать его nullable — миграция + правки во многих местах (вне скоупа). Поэтому контрагент остаётся обязательным и при «Сохранить как есть», но выбор быстрый (список или быстрое создание) и БЕЗ анализа/извлечения ПДн. При «Проверить на риски» — прежний флоу с извлечением сторон и предложением создать контрагента.

## Вне скоупа

- Изменение цен (генерация 100, правка 50, анализ 25 — фиксированы).
- Платёжный шлюз, покупка памяти (бесплатный объём фиксирован).
- Переписывание загруженного по образцу за 100 — остаётся доступным как «Переписать заново» на рабочем экране (уже есть), в мастер создания не возвращаем.

## Критерии приёмки

1. На главной, в сайдбаре и списке документов есть явная кнопка «Загрузить документ» с пометкой «бесплатно», ведущая на `/documents/upload`.
2. Мастер `/documents/new` не содержит вкладки загрузки файла — только «с нуля» и «из шаблона».
3. На `/documents/upload` после выбора файла есть две кнопки: «Сохранить в систему» (бесплатно) и «Проверить на риски · 25 токенов»; видна поясняющая плашка про платность будущих правок.
4. «Сохранить в систему» создаёт документ без единого списания токенов; документ появляется в списке, открывается на рабочем экране, показывает исходный текст.
5. Первая правка сохранённого документа через чат списывает 50 токенов и открывает пакет 10 правок.
6. При «Сохранить как есть» контрагент выбирается быстро (список/создание) без запуска анализа и извлечения ПДн; схему `counterpartyId` не меняем.
7. Цены не изменились: генерация 100, первая правка загруженного 50, анализ 25.
