## Итоги одной строкой

- **8 багов исправлено и задеплоено** (в т.ч. критические: обрыв договоров, перевёрнутые стороны, логаут, пустое приложение). Полноразмерные договоры (33k знаков) и приложения генерируются целиком.
- **Модели (Polza-only):** генерация (договор/приложение/ДС) → **Qwen3.6 Plus** (надёжна для всех типов, ~3–4 ₽); правки/чат/проверка → **DeepSeek V4 Flash** (~0,3 ₽). DeepSeek на генерации ломал приложения — поэтому генерация на Qwen. Маржа по документам всё равно ~99%.
- **Приложение/ДС строятся на тексте корневого договора** — подтверждено (ссылается на пункты родителя). Без корневого документа приложение не создать — это заложено в мастере.
- **Осталось:** допсоглашение, приложение-из-загруженного-файла, поведение при удалённом корне, проверка рисков, режим «Вопрос», покупка/скачивание — не дотестированы. Деньги/ПДн: настоящий SELECT FOR UPDATE в покупке, убрать ПДн из логов. Полный список — в `06`.

## Главное «что дальше» (топ-5)
1. Настоящий `SELECT FOR UPDATE` в покупке версии + убрать `console.log` с ПДн.
2. Дотестировать: допсоглашение, приложение-из-загрузки, поведение при удалённом корне, риски, «Вопрос», покупка, скачивание.
3. Код-доработка: маршрут генерации по типу документа (договор → дешёвый DeepSeek, приложение/ДС → Qwen) — чтобы вернуть экономию DeepSeek на основных договорах.
4. Нагрузка перед рекламой: индексы БД, WORKER_CONCURRENCY, rate-limit, общий volume.
5. Полировка UI: токен --font-serif, «мёртвые» кнопки, хардкод 540 ₽, битый роут /profile/requisites, адаптивность.
