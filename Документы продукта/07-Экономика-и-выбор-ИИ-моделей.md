## 3. Рекомендация по моделям

> ⚠️ **Важная корректировка после теста приложений:** DeepSeek V4 Flash — reasoning-модель, и на генерации **приложений/допсоглашений (child-docs) она возвращает ПУСТОЙ результат** (проверено вживую). Поэтому на генерацию ставим **Qwen3.6 Plus** — она надёжна и для договоров, и для приложений. Разница в цене (3–4 ₽ vs 0,3 ₽) несущественна: при цене версии 40–100 ₽ маржа всё равно ~99%.

### Генерация договоров, приложений, ДС → **Qwen3.6 Plus** ✅ (включено на проде)
- Работает для ВСЕХ типов документов (договор 33k знаков ✓, приложение 15,6k со ссылками на пункты родителя ✓).
- ~3–4 ₽/договор, качество высокое, лимит вывода 65k токенов.
- DeepSeek V4 Flash даёт 0,3 ₽ на ОСНОВНЫХ договорах, но ломается на приложениях — до код-фикса (маршрут child-docs отдельно) держим Qwen для всей генерации.

### Правки / чат / быстрый анализ → **DeepSeek V4 Flash** (через дефолт)
- Дёшево (~0,26 ₽/правка), правки на большом договоре держат контекст (проверено на 33k — правка одного пункта не задела остальное).
- ⚠️ Отдельного A/B качества правок не делал — рекомендую сравнить с Qwen3.5 Plus на серии правок.

### Проверка рисков (review) → **Qwen3.6 Plus** ✅ (проверено вживую)
- **На DeepSeek V4 Flash review ПАДАЛ** с ошибкой «Unexpected end of JSON input» — reasoning-модель отдаёт неполный/битый JSON, а review требует строгий JSON-отчёт.
- **На Qwen3.6 Plus — отлично:** оценка 76/100, «3 риска / 6 замечаний / 6 OK», ссылки на конкретные пункты (п.2.12, 6.5, 3.5, 5.9), категории Финансы/Суд, документ-специфичное резюме.

### Чат «Вопрос» → **DeepSeek V4 Flash** ✅ (проверено вживую)
- Отличный документ-специфичный ответ (уровень защиты пункта, ссылки на ст. 333 ГК РФ, расчёты), документ не меняется. Работает как задумано.

### Ключевой вывод по DeepSeek V4 Flash
DeepSeek V4 Flash — reasoning-модель. **Ломается на СТРУКТУРНЫХ задачах** (генерация приложений → пусто; review → битый JSON). Годится для ТЕКСТОВЫХ (основной договор, чат, правки). Поэтому структурные задачи и всю генерацию — на Qwen3.6 Plus.

### Защита пайплайна (задеплоено)
- Воркер больше НЕ сохраняет пустой черновик: при результате короче 200 знаков бросает ошибку → BullMQ повторяет задачу (коммит `e33535b`). Страхует от «Документ пуст» при сбое любой модели.

### Итоговая конфигурация на проде (после сессии)
- Операторы: только **Polza.ai** (GigaChat, OpenRouter — выключены).
- **Генерация** (договор/приложение/ДС) → **Qwen3.6 Plus**.
- **Проверка рисков, анализ, извлечение сторон** (структурные) → **Qwen3.6 Plus**.
- **Правки, чат, орфография** (текстовые, дёшево) → **DeepSeek V4 Flash**.

### Идеал (код-доработка на будущее)
- Разделить генерацию по типу документа: основной договор → DeepSeek V4 Flash (0,3 ₽, работает), приложение/ДС → Qwen. Сейчас задача `generate` одна на все типы, поэтому вся генерация на Qwen (надёжнее).
- Вынести review в BullMQ (сейчас синхронно, ~2,5–3 мин на 33k-договор, риск таймаута nginx 300с).

## 4. Экономика в разрезе продаж

### Себестоимость (реальные данные из usage-лога `/admin/ai`)
| Операция | Модель | Себестоимость |
|---|---|---|
| Генерация договора (23–33k знаков) | DeepSeek V4 Flash | ~0,30 ₽ |
| Генерация договора (23–33k знаков) | Qwen3.6 Plus (на проде) | ~1,8–4 ₽ |
| **Генерация ДС/приложения (компактное, ~8k знаков)** | Qwen3.6 Plus | **~1,57 ₽** (замер: 10 842 токена, 116 сек) |
| Правка через чат | DeepSeek V4 Flash | ~0,26 ₽ |
| Правка (замер по логу edit) | средн. по 12 правкам | ~0,43 ₽ |
| Проверка рисков (review) | Qwen3.6 Plus | ~2,57 ₽ |
| Чат «Вопрос» | DeepSeek V4 Flash | ~0,20 ₽ |
| Полный цикл (генерация + проверка + 2–3 правки) | смешанно | ~2,5–5 ₽ (Qwen) / ~1–1,5 ₽ (DeepSeek) |
| Хранение (Yandex Object Storage) | — | ~0 ₽ (доли копейки) |

> **Замер по конкретному компактному ДС** (последний тест, ООО «Медикал сити групп», 8 131 знак, смета-таблица с фото/видео): **1,567 ₽** на Qwen3.6 Plus. Итог из usage-лога: `generate` 20,0 ₽ / 11 запусков ≈ 1,82 ₽ средн.; `edit` 5,16 ₽ / 12 ≈ 0,43 ₽; `review` 2,57 ₽; `chat` 0,20 ₽.

### Цены (из `lib/pricing.ts`, действуют) и маржа
| Услуга | Цена | Себест. | Маржа |
|---|---|---|---|
| Договор ≤20k знаков | 50 ₽ | ~0,3–0,5 ₽ | **~99%** |
| Договор ≤40k | 60 ₽ | ~0,5 ₽ | **~99%** |
| Договор >40k | 100 ₽ | ~0,8 ₽ | **~99%** |
| Приложение / Допсоглашение (Qwen, замер) | 40–100 ₽ | ~1,57 ₽ | **~96–98%** |

> Даже с учётом реальной себестоимости Qwen3.6 Plus на компактном ДС (~1,57 ₽) маржа при цене 40–100 ₽ остаётся **96–98%**. Если перевести генерацию основных договоров на DeepSeek V4 Flash (0,3 ₽) — маржа ~99%.

**Ключевой вывод для бизнес-плана:** с DeepSeek V4 Flash себестоимость ИИ ничтожна (~0,3–1,5 ₽ на полный цикл документа). Это радикально меняет юнит-экономику в лучшую сторону — маржа по документам **~99%** даже на текущих низких ценах (40–100 ₽). Есть большой запас: можно (а) держать низкие цены для захвата рынка, (б) поднять цены до 149 ₽ (см. `02-Бизнес-план.md`) при марже ~99%, (в) щедро давать бесплатный первый документ (себестоимость ~0,3 ₽).

### Обновление к бизнес-плану
Оценка себестоимости в `02-Бизнес-план.md` (~30 ₽/документ на GigaChat-2-Max) была **консервативной и завышенной**. Реальная себестоимость на выбранной модели (DeepSeek V4 Flash) — **~0,3–1,5 ₽ на документ**, то есть в 20–100 раз ниже. Прайсинг и маржа из бизнес-плана остаются валидными и даже более выгодными.
